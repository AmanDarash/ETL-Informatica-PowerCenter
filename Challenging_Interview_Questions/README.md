# Challenging Interview Questions

This folder contains Informatica PowerCenter mappings and workflows that solve common ETL interview problems.  
Each subfolder includes:
- **Mapping XML** → Exported mapping file
- **Workflow XML** → Workflow to run the mapping
- **notes.md** → Explanation of logic and reasoning

## Included Scenarios
- Duplicate vs Unique Segregation
- Max Salary per Department
- Join Strategies
- Slowly Changing Dimensions
- Error Handling
