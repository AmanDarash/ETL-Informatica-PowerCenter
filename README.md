# ETL-Informatica PowerCenter

This repository contains a collection of ETL projects and mappings designed in **Informatica PowerCenter**.  
It showcases solutions to real-world scenarios, challenging interview problems, and reusable components for efficient ETL design.

---

## 📂 Repository Structure

### 🔹 Core Projects
- **Project1_MaxSalaryMapping/** → Mapping to replicate max salary per department
- **Project2_DuplicateHandling/** → Mapping to remove duplicates using sorter/aggregator
- **Project3_JoinStrategies/** → Different join strategies for performance optimization
- **CommonReusableTransformations/** → Reusable lookups, expressions, and mapplets

### 🔹 Challenging Interview Questions
Mappings and workflows commonly asked in ETL interviews, with detailed explanations:
- [Duplicate vs Unique Segregation](Challenging_Interview_Questions/Duplicate_Unique_Segregation_Mapping/)
- [Duplicate vs Unique Segregation using Dense Ranking](Challenging_Interview_Questions/Duplicate_Unique_DenseRank_Mapping/)
- [First And LastRow Extractor](Challenging_Interview_Questions/FirstLastRowExtractor/)
- [Alternate Record Split](Challenging_Interview_Questions/AltRecordSplitter/)
- [Add Previous Row Salary](Challenging_Interview_Questions/AddPreviousRowSalary/)
- [Error Handling](Challenging_Interview_Questions/Error_Handling/)

## 🎯 Goals
- Demonstrate ETL design skills with practical examples
- Provide reusable frameworks for common scenarios
- Document troubleshooting and optimization techniques

## 🛠️ How to Use
1. Import the XML mappings into Informatica PowerCenter.
2. Navigate to the relevant project or interview scenario folder.
3. Review the `notes.md` in each folder for logic explanation and reasoning.
4. Run workflows to validate transformations.
